# PRD — 속초모아 원문·위치 안내·관리자 UI 안정화

## 목표

모든 운영 행사의 공식 원문과 위치를 실제 콘텐츠까지 검증하고, 상세 화면에는 과금 가능한 지도 미리보기 없이 검증된 장소·주소와 외부 지도 링크만 제공하며, 이미지 대체 화면과 관리자 상태 변경 UI를 안정화한다.

## 작업 분류와 검증 강도

- 주 작업 유형: `bugfix`
- 보조 유형: 지도 미리보기 제거와 UI 안정화
- 검증 엄격도: `strict`
- `artifact_only`: `false`

## 대상 사용자와 주요 흐름

- 행사 이용자: 행사 상세에서 정확한 공식 원문·장소·주소를 확인하고 필요할 때 외부 지도 서비스를 연다.
- 운영자: 공개·비공개·반려 상태를 화면 흔들림 없이 변경하고, 검증 근거가 있는 원문과 좌표만 저장한다.
- 주요 흐름: 행사 목록 → 상세 → 공식 원문·장소·주소 확인 → 필요 시 외부 지도 링크 사용.

## 현재 재현된 문제

1. `2026년 풀이음친구랑 무비 나잇`의 원문 URL이 `mode=view`를 사용해 행사 상세가 아니라 목록으로 해석된다. 공식 상세 URL은 `articleseq=11208&bmode=view`다.
2. 공식 원문 검증이 외부 ID 존재 여부만 확인하여, 잘못된 쿼리나 soft 목록 페이지도 통과할 수 있다.
3. 지도 SDK의 무료 범위와 대표 계정 조건을 운영자가 보장하기 어려워, 상세 위치 영역의 인라인 지도 미리보기가 예기치 않은 과금 위험을 만든다.
4. 이미지가 없으면 `공식 이미지 준비 중` 문구가 크게 노출되고, URL이 있으나 로딩에 실패한 이미지는 대체 배경으로 전환되지 않는다.
5. 관리자 상태 변경 중 버튼 라벨과 live status 높이가 바뀌고 테이블 열이 재계산되어 현재 행과 인접 행이 움직인다.

## 감사 집계 정의

- 관리자 전체 행 `A=28`: 공개·비공개·반려 상태 보존과 데이터 누락 여부를 전수 확인하는 모수다.
- 실제 운영 행사 `N=20`: `is_demo=false`이며 공식 원문·위치 감사와 운영 `N/N` 완료율의 모수다.
- 비운영 샘플 `D=8`: `is_demo=true`이고 제목에 `[샘플]`이 표시된 UI fixture다. 실제 행사가 아니므로 존재하지 않는 공식 원문을 만들지 않으며, 관리자 전수표에 제외 근거를 남기고 그대로 보존한다.
- 관계는 `A=N+D=28`로 고정한다. 운영 원문 완료 표기는 `20/20`, 관리자 행·상태 보존 표기는 `28/28`로 각각 기록한다.

## 완료 기준

### AC-1 운영 행사 공식 원문 전수 정확성

- Goal 시작 시 관리자 전체 행사 수를 `A=28`로 고정해 공개·비공개·반려 전체를 감사하고, 이 중 실제 운영 행사 `N=20`의 공식 원문을 검증한다.
- 각 `source_url`은 주최·운영기관의 HTTPS 상세 페이지이거나, 상세 페이지가 없을 때만 행사별 공식 파일이어야 한다.
- 리다이렉트 후 정상 응답이어야 하며 홈·목록·로그인·soft-404가 아니어야 한다.
- 상세 페이지는 행사명과 행사 날짜 또는 장소 중 하나 이상이 운영 데이터와 일치해야 한다. 공식 파일은 행사명과 날짜를 시각 확인한다.
- 무비 나잇 URL은 `https://www.sokchosiseol.or.kr/bbs/event.do?articleseq=11208&bmode=view`로 교정한다. `mode=view`, `bmode` 누락, 목록 URL은 검증에서 거부한다.
- 공식 사이트 외곽의 잘못된 섹션 제목은 상세 ID·행사 제목·날짜·본문이 일치할 때 원문 실패로 보지 않는다.
- `events.source_url`을 노출 기준으로 삼고 교정된 `event_sources` 행에 `external_id`와 확인 시각을 기록한다. 잘못된 과거 출처 행은 삭제하지 않는다.
- Vercel 운영 화면과 관리자 감사표의 실제 운영 원문 `N/N=20/20`이 올바른 행사별 원문을 열어야 하며, 비운영 샘플 `D=8`은 제외 사유와 상태 보존을 확인한다.

### AC-2 검증 위치 안내와 무과금 외부 지도 링크

- 상세 화면에서 인라인 지도·iframe·지도 SDK·지도 로딩/fallback 박스를 모두 제거한다.
- 장소명과 상세 주소는 텍스트로 계속 표시하고, 비용이 발생하지 않는 일반 외부 지도 링크는 작은 텍스트 링크로 유지한다.
- 완전한 좌표 쌍이 있는 단일 장소는 검증 좌표를 외부 링크에 사용하고, 좌표가 없는 행사는 장소명·주소 검색 링크만 만든다. 임의 좌표나 속초 중심점은 사용하지 않는다.
- 기존 공식 주소·카카오 POI 교차 확인 좌표·위치 근거 URL·확인 시각과 DB 제약은 향후 재도입을 위해 보존한다.
- 지도용 공개 환경 변수와 SDK loader를 제품 계약에서 제거하고, 데스크톱·모바일 운영 화면에서 카카오·네이버 지도 SDK 요청이 0건이어야 한다.
- 장소명·주소·외부 링크에 접근 가능한 이름을 제공하고, 지도 미리보기 제거로 빈 고정 높이 영역이 남지 않아야 한다.

### AC-3 무문구 이미지 대체 화면

- 이미지가 없거나 빈 URL이면 기존 그라데이션 배경만 표시하고 시각적 문구와 pill을 제거한다.
- 이미지 404·네트워크 로딩 실패도 같은 배경으로 전환한다.
- 시각적 문구 없이 스크린리더용 행사 대표 이미지 설명을 유지한다.
- 목록 16:9와 상세 이미지 영역은 로딩 전후 크기가 변하지 않는다.

### AC-4 관리자 상태 변경 무이동

- 공개·비공개·반려 버튼의 라벨과 너비는 저장 중에도 바뀌지 않는다.
- 저장 상태는 크기를 바꾸지 않는 spinner, `aria-busy`, `aria-live`로 전달한다.
- 상태 badge와 작업 영역 폭을 안정화하고 오류는 레이아웃을 밀지 않는 알림으로 표시한다.
- 성공·실패 rollback 모두에서 버튼 영역·현재 행·인접 행의 좌표와 크기 변화가 1 CSS px 이하여야 한다.
- 관리자 목록과 수정 화면을 데스크톱·모바일에서 확인한다.

### AC-5 배포·회귀·상태 보존

- lint, typecheck, unit, production build, 데스크톱·모바일 E2E가 모두 통과한다.
- 운영 데이터 변경 전 `events`와 `event_sources`를 백업하고 기존 검수 상태를 보존한다.
- 운영 배포에서 원문 `N/N`, 지도 미리보기·SDK 요청 0건, 위치 텍스트·외부 링크, 이미지 fallback, 관리자 무이동을 확인하고 브라우저 콘솔 오류가 없어야 한다.
- 관리자 상태 검증 후 테스트한 행을 원래 상태로 복구하고 전체 상태 개수가 변경 전과 같아야 한다.

## 인터페이스와 데이터 계약

- `events`에 `location_source_url text`, `location_verified_at timestamptz`를 추가한다.
- `events`의 `latitude`와 `longitude`는 둘 다 `null`이거나 둘 다 값이 있도록 DB 제약과 애플리케이션 검증을 둔다.
- 공개 `Event` 매핑에 위치 근거와 위치 확인 시각을 nullable 필드로 추가한다.
- 외부 지도 링크는 위도·경도 쌍이 모두 있으면 검증 좌표를 사용하고, 그렇지 않으면 장소명·주소 검색만 사용한다.
- 새로운 공개 HTTP API는 추가하지 않는다.

## 운영·외부 설정

- 지도 플랫폼 계정·결제수단·Client ID·도메인 등록은 사용하지 않는다.
- Vercel과 로컬 환경에 지도용 공개 환경 변수가 없어도 모든 위치 안내와 외부 링크가 동작해야 한다.
- 기존 Vercel 지도 환경 변수는 새 배포에서 참조되지 않아야 하며, 운영 확인 후 별도 비밀값 노출 없이 삭제할 수 있다.
- 인라인 지도 재도입은 서비스 성장 뒤 비용·한도·제공자 정책을 새로 승인하는 별도 작업으로 연기한다.

## 비범위

- 이미지 검색, 권리 미확인 이미지 복제·핫링크
- 네이버·카카오 등 모든 인라인 지도 SDK·iframe·정적 지도 미리보기
- 추정 좌표, 행정동 중심점, 다중 장소의 임의 대표 핀
- 일반 목적 크롤러 또는 모든 외부 사이트를 자동 판정하는 공개 endpoint
- 전체 UI 재설계, 행사 스키마의 무관한 변경
- 잘못된 과거 `event_sources` 기록의 파괴적 삭제

## 보호할 기존 변경

- 기존 카카오 키나 시험한 네이버 인증값은 문서·커밋·출력에 노출하지 않으며 제품 코드와 환경 계약에서 지도 키 참조만 제거한다.
- 기존 행사·출처·검수 상태와 사용자의 다른 작업트리 변경을 명시적 지시 없이 되돌리지 않는다.

## 결정된 기본값

- 지도 제공자: 없음. 장소·주소와 일반 외부 지도 링크만 제공
- 원문 감사 범위: 관리자 전체 `A=28`을 분류하고 실제 운영 `N=20`의 원문을 검증하며 비운영 샘플 `D=8`의 제외 근거를 기록
- 공식 페이지 판정: 상세 ID·행사 본문이 일치하면 외곽 섹션 제목 오류와 무관하게 인정
- 남은 제품 결정: 인라인 지도 재도입은 현재 Goal 밖의 미래 결정
