# PLAN — 속초모아 원문·위치 안내·관리자 UI 안정화

## 목표

모든 운영 행사의 공식 원문과 위치를 실제 콘텐츠까지 검증하고, 상세 화면에서 과금 가능한 지도 미리보기를 제거한 채 장소·주소와 외부 지도 링크를 제공하며, 이미지 대체 화면과 관리자 상태 변경 UI를 안정화한다.

## 참조 문서

- PRD.md (`docs/goaljaby/sokcho-source-inline-map-stability/PRD.md`)
- VALIDATION.md
- RECOVERY.md
- PROGRESS.md

## 마일스톤 1: 기준선·운영 감사·재현

- 범위: 작업트리와 현재 검증 기준 확인, `events`·`event_sources` 백업, 관리자 전체 `A=28`·실제 운영 `N=20`·비운영 샘플 `D=8` 고정, 원문·위치 감사표 생성, 무비 나잇 `mode=view`와 관리자 레이아웃 이동 수치 재현.
- 완료 조건: 변경 전 데이터·상태 스냅샷과 행사별 원문·위치 판정이 남고, 원래 두 결함을 반복 가능한 증거로 재현함.
- 검증: baseline 필수 명령, 원문 최종 URL·본문 대조, 관리자 전·중·후 bounding box 기록.

## 마일스톤 2: 공식 원문 교정과 재발 방지

- 범위: 시설관리공단 `bmode=view` 등 기관별 상세 URL 규칙, URL canonicalization, 원문 UI 계약, 전체 운영 `source_url`과 `event_sources` 보정.
- 완료 조건: 무비 나잇을 포함한 실제 운영 행사 `N/N=20/20`이 공식 상세 원문 또는 검증된 공식 파일을 가리키고, 샘플 `D=8`의 제외 근거와 전체 `A=28`의 상태가 보존되며 잘못된 과거 출처는 삭제되지 않음.
- 검증: URL 규칙·fixture 단위 테스트, 데이터 재조회, 운영 브라우저에서 행사 제목과 날짜 또는 장소 대조.

## 마일스톤 3: 위치 근거와 무과금 위치 안내

- 범위: 위치 근거 필드와 좌표 쌍 migration, 타입·admin 입력 검증, 단일 장소 좌표 backfill을 보존하고, 모든 인라인 지도·SDK·로딩/fallback 박스를 제거한다. 장소·주소와 일반 외부 지도 링크만 유지한다.
- 완료 조건: 모든 상세 화면에 지도 미리보기나 빈 지도 영역이 없고, 검증 위치 데이터는 보존되며 외부 링크가 올바르게 동작한다.
- 검증: migration·스키마와 좌표 쌍 테스트, SDK script/network 요청 0건 E2E, production 위치 텍스트·외부 링크·접근성 확인.

## 마일스톤 4: 이미지 fallback과 관리자 UI 안정화

- 범위: null·빈 URL·로드 실패 이미지의 무문구 배경, 상태 버튼 고정 라벨·고정 크기 spinner·접근성 상태, badge·작업 셀 안정화와 실패 rollback.
- 완료 조건: 이미지 프레임이 유지되고 시각적 준비 문구가 없으며, 관리자 성공·실패 중 관련 영역 이동이 1 CSS px 이하임.
- 검증: 이미지 3종 회귀, 관리자 데스크톱·모바일 bounding box, 접근성 이름·`aria-busy`·`aria-live` 확인.

## 마일스톤 5: 전체 검증·배포·운영 감사

- 범위: 전체 자동 검증, DB migration·보정 보존, 지도 환경 계약·SDK 제거, production 배포, 전체 원문·위치 안내·이미지·관리자 감사와 상태 복구.
- 완료 조건: 필수 명령이 모두 통과하고 운영 원문 `N/N`, 지도 미리보기·SDK 요청 0건, 콘솔 오류 0건, 상태 개수 보존을 증명함.
- 검증: VALIDATION.md 전체와 production 데스크톱·모바일 감사, 배포 ID·커밋·데이터 재조회 기록.
