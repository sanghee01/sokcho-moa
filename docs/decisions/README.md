# 결정 기록

재구축하며 **내가 내린 판단**을 남기는 곳입니다. AI는 이 폴더에 결정이 있을 때만 삭제·리팩토링·구조
변경을 합니다([RULES.md의 재구축 원칙](../../.ai/RULES.md#재구축-원칙)).

## 규칙

- 파일 이름: `NNNN-짧은-제목.md` (예: `0001-supabase-client-선택-기준.md`). 번호는 순서대로 붙이고 재사용하지 않습니다.
- 문서 안에서는 `D-0001`처럼 부릅니다. PR 본문과 CONVENTIONS.md 규칙에서 이 ID로 링크합니다.
- 새 결정은 [`_template.md`](_template.md)를 복사해 씁니다.
- 결정을 바꾸면 기존 문서를 고치지 않고 새 결정을 만든 뒤, 기존 문서 상태를 `대체됨(D-NNNN)`으로 바꿉니다.
  판단이 바뀐 과정이 남아야 하기 때문입니다.
- "내 설명", "결정", "이유"는 내가 씁니다. AI는 "AI가 확인한 사실"과 "질문"만 채웁니다.

## 상태

| 상태 | 뜻 |
| --- | --- |
| 초안 | 설명·사실 정리 중. AI는 이 결정으로 작업하지 않음 |
| 결정됨 | AI에게 맡길 범위가 확정됨 |
| 완료 | 작업과 검증이 끝남 |
| 대체됨(D-NNNN) | 다른 결정으로 바뀜 |
