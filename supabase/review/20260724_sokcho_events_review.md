## SQL 적용 방식

1. Supabase SQL Editor에서 [`20260724_sokcho_events_review.sql`](./20260724_sokcho_events_review.sql) 전체를 실행한다.
2. 마지막 조회 결과가 9행이고 모두 `pending`인지 확인한다. 신규 행사는 공개 화면에 자동 노출되지 않는다.
3. `/admin`에서 속초교육도서관 3강좌의 개별 수업일·비용, 가족센터 프로그램의 정확한 시각·접수 마감일을 확인한다.
4. 확정된 행사만 관리자 화면에서 공개한다. 장사항 버스킹은 위 수정 권고에 따라 별도로 고친다.

SQL은 같은 slug가 이미 `published`이면 전체 트랜잭션을 중단한다. 같은 slug의 `pending`·`rejected` 후보에만 최신 검증 내용을 덮어쓰며, 운영 DB에는 아직 실행하지 않았다.
