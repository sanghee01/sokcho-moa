## 정확성 주의사항

- 늘봄학교 공식 게시물과 첨부 안내문은 `7월 27일~8월 5일, 총 8회`까지만 명시하고 개별 회차 날짜를 나열하지 않는다. SQL의 7월 27~31일·8월 3~5일은 해당 기간의 평일 8일로 구조화한 값이다. 게시 전 청소년수련관(`033-630-6282`, `033-630-6286`)에 개별 운영일을 한 번 확인하는 것이 가장 안전하다.
- 시설관리공단 본문은 종료 시각 없이 `7월 21일`로 표시하지만 첨부 안내문은 신청 마감을 `7월 21일 18:00`으로 명시한다. SQL은 더 상세한 첨부파일 값을 사용했다.
- 늘봄학교 게시물에 `8월 5일(월)`이라는 요일 오기가 있으나 2026년 8월 5일은 수요일이다. SQL은 날짜를 기준으로 저장했다.
- 숏폼 공모전과 독서퀴즈는 무료라고 명시하지 않았다. 요금 안내가 없다는 사실만 기록하고 `is_free = null`로 뒀다.
- 대포야 사랑해는 매주 토요일이라는 표현과 달리 공식 카드뉴스에 8월 1일 회차가 없다. SQL은 카드뉴스의 6개 날짜만 넣었다.
- 청초호 물놀이터의 우천 휴장은 미리 날짜를 알 수 없어 62개 정규 운영일만 회차로 넣었다. 실제 당일 운영 여부는 기상 상황을 다시 확인해야 한다.
- 무소음 DJ 파티는 초기 기사에서 8월 3~5일로 안내됐으나 7월 20일자 최신 속초시 공지는 8월 3~4일로 정정됐다. 아직 시간·가격·신청 방식은 공개되지 않아 값을 만들지 않았다.
- 빛의 바다는 평상시 여름철 금·토 21:00·22:00 운영이지만, 2026년 속초해수욕장 야간개장 기간에는 7월 21일~8월 12일 매일 운영한다. SQL은 이 특별 운영 46회를 넣었다.
- 해양레포츠 공식 상세 포스터는 1·2차 기간은 명시하지만 기간 중 휴무 요일은 명시하지 않는다. SQL은 일별 일정을 추정하지 않고 두 운영기간을 각각 하나의 회차 범위로 저장했다.

## SQL 적용 방식

1. Supabase SQL Editor에서 전체 파일을 한 번에 실행한다.
2. 마지막 조회 결과가 9행인지 확인한다. 새 데이터는 모두 `pending`이고 공개 화면에는 나오지 않는다.
3. `/admin`에서 원문, 날짜, 가격, 장소를 최종 검토한다. 특히 늘봄학교 개별 8회 날짜와 아직 미공개인 DJ 파티 세부사항을 확인한다.
4. 확정된 행사만 관리자 화면에서 공개한다. 관리자 공개 동작을 거치면 Next.js 데이터 캐시도 함께 갱신된다.

운영 DB에 SQL을 바로 실행해도 공개되지는 않지만, 이 파일을 `supabase/migrations`에 옮기거나 `published`로 바꿔 실행하면 안 된다. SQL Editor의 직접 수정은 애플리케이션 캐시 무효화를 호출하지 않으므로 이미 공개된 동일 slug가 있으면 안전장치가 트랜잭션을 중단한다.
