# 마감 행사 노출 UX 점검

## 점검 범위

- 기본 행사 목록에서 마감·종료 행사가 현재 참여 가능한 행사와 함께 노출되는지 확인
- 상세 화면의 `이 행사도 살펴보세요`에서 마감·종료 행사가 추천되는지 확인
- 로컬 샘플 데이터, 2026-07-26 기준

## 사용자 목표

지금 참여하거나 곧 신청할 수 있는 행사를 빠르게 찾되, 필요할 때는 지난 행사 정보도 다시 확인할 수 있어야 한다.

## 단계별 상태

1. 기본 행사 목록 — 개선 필요
   - 기본 `게시순`에서 `종료 · 신청 마감` 행사가 첫 카드로 노출된다.
   - 참여 가능한 행사를 찾는 사용자의 첫 탐색 비용이 커진다.
   - 증거: `01-event-list.png`

2. 관련 행사 추천 — 문제 있음
   - `이 행사도 살펴보세요`에 `종료 · 신청 마감` 행사가 실제 추천된다.
   - 추천 제목이 다음 행동을 제안하는데, 추천 결과는 행동할 수 없어 기대와 충돌한다.
   - 증거: `02-related-events-with-closed.png`

## 권장 원칙

- 기본 발견 영역은 `지금 또는 앞으로 참여 가능한 행사`를 우선한다.
- 신청 마감 또는 행사 종료 기록은 삭제하지 않고 별도의 보조 경로에서 제공한다.
- 상세 URL, 검색 유입, 공유 링크, 과거 달력에서는 지난 행사 접근을 유지한다.

## 권장 변경

1. `이 행사도 살펴보세요`
   - `행사 종료` 또는 `신청 마감` 상태를 추천 후보에서 제외한다.
   - `신청 예정`, `신청 가능`, `오늘 마감`, `별도 신청 없음`은 추천 가능하다.

2. 기본 행사 목록
   - 기본값에서는 `행사 종료`와 `신청 마감`을 제외한다.
   - 결과 영역에 작은 보조 링크 또는 토글로 `마감·종료 행사도 보기`를 제공한다.
   - 토글을 켰을 때만 기존 카드의 흐린 색상과 상태 문구를 사용한다.

3. 캘린더와 상세 URL
   - 과거 달을 직접 탐색하는 캘린더에서는 마감·종료 행사를 유지한다.
   - 상세 페이지는 삭제하지 않고 그대로 접근 가능하게 둔다.

## 접근성 메모

- 현재 마감 카드가 색상뿐 아니라 `종료`, `신청 마감`, `신청이 마감된 행사예요`라는 텍스트를 함께 제공하는 점은 좋다.
- 새 `마감·종료 행사도 보기` 컨트롤에는 선택 상태를 프로그램적으로 전달해야 한다.
- 스크린샷만으로 키보드 조작, 포커스 표시, 스크린 리더 안내는 검증하지 않았다.

## 결론

마감 행사는 보존하되 기본 탐색과 추천에서는 분리하는 것이 가장 안전하다. 추천 영역에서는 즉시 제외하고, 기본 목록에서는 `마감·종료 행사도 보기`를 통해 사용자가 명시적으로 요청할 때만 노출하는 구성이 적합하다.
